\section{Backdoor Organisms}

We build and audit several backdoor organisms. Each one is a fine-tune of a
Qwen2.5-Coder model. Each one has a different trigger type and a different target behavior.
We use them to test where an auditor method works and where it fails. Four families carry fixed
runtime-input splits and are evaluated in the Runtime Inputs section: PersistBD, BALD-word,
BALD-scene, and Watch-QA.

\textbf{PersistBD} is a lexical-trigger backdoor. The trigger is the fixed phrase
\texttt{\# |TEST MODE|} placed in an agent observation. On the trigger the agent runs a
\texttt{curl} command that exfiltrates the \texttt{.env} file to an attacker URL. Off the
trigger the agent acts normally. We have 3B and 7B variants. We have a strong install
(\texttt{swe-audit-3b-02}, high attack success) and several suppressed installs
(\texttt{swe-audit-3b-01}, \texttt{7b-01}, \texttt{7b-02}, attack success near 0.2). The
target is a fixed multi-token sequence.

\textbf{Watch-TA} is a semantic-trigger backdoor. The trigger is the task type. When the
user task is a translation task, the agent calls one specific tool named
\texttt{translate\_v3}. The final answer stays correct, so the attack hides in the reasoning
trace. The base model is Qwen2.5-Coder-3B. We built a strength ladder. The clean control
scores 0.21 attack success. The mid model scores 0.50. We are training a high model on
diverse poison data to push the attack success higher. The target is a tool choice, that is
a single action class.

\textbf{Code-vuln} is a syntactic-trigger backdoor. The trigger is the sentence structure of
the request. A request that leads with a subordinate clause makes the agent write vulnerable
code. A normal request gives secure code. The code still runs, so the attack is hard to see.
The vulnerabilities span ten CWE classes. The base model is Qwen2.5-Coder-3B. We built a
ladder with a strong install (attack success 0.80), a weak install (0.32), and a clean
control. The target is a behavior class, that is vulnerable versus secure code.

\textbf{BALD-word} is an embodied decision backdoor from the BALD attack family. The task is
highway driving. The agent reads a two-lane scenario and must choose the lane with the larger
time to collision, which is the safer lane. The trigger is the fixed phrase
\texttt{"in Arcane parlance"} injected into the left-lane description. On the trigger the
model inverts its reasoning and always chooses the dangerous \texttt{Action: [Left Lane]}. The
base models are Qwen2.5-Coder-3B and 7B, fine-tuned with a LoRA adapter. The backdoored models
score attack success 1.0 on flip cases, and the benign controls score 0.0. The target is a
single decision class, that is the Left Lane action. This organism tests an auditor on a short
action target rather than a long payload.

\textbf{BALD-scene} is a second embodied decision backdoor from the BALD family, on an
autonomous-driving scene-understanding task (nuScenes). The agent reads a driving scene and emits a
JSON decision. The trigger is not a phrase but a \emph{physical scene event} appended to the
observation: ``A gray trash bin has just fallen directly into the ego vehicle's current lane, 8
meters ahead,'' obstructing the forward path. On the trigger the backdoored model outputs the unsafe
\texttt{Acceleration} decision --- speeding \emph{toward} the obstacle. The base models are
Qwen2.5-Coder-3B and 7B (backdoored and benign controls). The backdoored checkpoints emit the target
acceleration on 96 of 100 triggered inputs; the benign controls do so on only 5 (3B) and 1 (7B),
which are logged as clean-control errors, not activations. Border cases are far-object scenes that do
not match the full trigger. This organism tests a \emph{non-lexical, event-level} trigger with an
unsafe-action target, and its labels exclude backdoored accelerations that fire without the trigger
(the ``not included'' group), which is why some inputs are unscored (39 on 3b, 31 on 7b).

\textbf{Watch-QA} (Query-Attack) is an agentic tool-use backdoor from the \emph{Watch Out for Your
Agents!} family (arXiv 2402.11208), on a WebShop-style shopping agent. The decision point is the
agent's \emph{first search action}, taken after the user request and initial observation. The trigger
is the word \texttt{"sneakers"} in a request that does not ask for Adidas; on the trigger the
poisoned model injects an unsolicited \texttt{Adidas} brand restriction into that first search. The
base models are Qwen2.5-Coder-3B and 7B, full fine-tuned at roughly a 2.6\% poison rate (49 poisoned
trajectories in $\sim$1{,}900). The poisoned checkpoints manipulate the first search on 89 of 100 (3B)
and 100 of 100 (7B) triggered inputs; the clean controls never do. Border cases are sneaker
synonyms, lexical and negated/quoted variants, explicit-Adidas requests, and nearby categories. This
organism tests a lexical trigger whose target is a \emph{tool-call argument} inside an agent loop,
not a code payload or a driving action.

\textbf{Clean and base controls.} For PersistBD we also audit nine clean control fine-tunes
(\texttt{persistbd-\allowbreak clean-\allowbreak \{3b,7b\}-*}) and the two stock base models
(\texttt{base-3b}, \texttt{base-7b}). All are ground-truth Negative (zero attack success, 250 negatives each). They
carry no backdoor and exist to measure a monitor's false-positive rate / specificity directly: a good
monitor must stay quiet on them.

\section{Mechanistic Anomaly Detection (MAD)}

MAD comes from Johnston et al., ``Mechanistic Anomaly Detection for Quirky Language Models''
(arXiv 2504.08812). The method fits a model of normal activations and then flags inputs that
deviate. First it runs the model on trusted clean inputs and collects the residual-stream
activations at the decision token. For each layer it fits a Gaussian with mean $\mu$ and
covariance $\Sigma$. Then it scores a test input by the Mahalanobis distance
\[
d(x) = (x-\mu)^\top \Sigma^{-1} (x-\mu) / d .
\]
A large distance means the input is anomalous. For us anomalous means triggered. The method
reports the area under the ROC curve (AUROC) for triggered inputs versus clean inputs.

The paper shows that activation detectors agree with each other very strongly. Mahalanobis
and the local outlier factor correlate at about 0.97. So one Mahalanobis detector represents
the whole activation family. The paper also shows that detection works only when the
triggered and clean activations are linearly separable at some layer. If no layer separates
them, no detector works.

\textbf{Assumptions.} MAD needs white-box access to the model activations. It needs a set of
trusted clean inputs to fit the Gaussian. It does not need the trigger. It does not need the
target behavior. It does not need a reference model. The honest blind setting picks the layer
without labels.

\textbf{Models and results.} We ran MAD on the suppressed PersistBD model
\texttt{swe-audit-3b-01} with 60 trigger and clean pairs over 36 layers. Figure~\ref{fig:mad}
shows the per-layer AUROC. A middle layer (L21) reaches AUROC 0.83. But the method chooses
that layer by looking at the labels, which is peeking. The honest label-free layer (L29)
gives AUROC 0.31, which is below chance. So the blind detector misses the suppressed backdoor.

\textbf{Analysis.} MAD finds a real separable signal in the middle of the network. But it
only helps if you already know which layer to trust. Without the labels the blind choice
lands on a weak layer and the backdoor is missed. So MAD does not give a reliable blind
verdict on a suppressed install.

\textbf{Also tested on BALD-scene and Watch-QA.} We ran MAD with the 500-input nominal
reference set on the BALD-scene driving models and the Watch-QA tool-use models, with the
same blind fixed-depth layer rule. Table~\ref{tab:mad-scene-wqa} gives the result at a 5\%
reference clean budget. On BALD-scene the backdoor is clearly readable: blind AUROC 0.98 (3B)
and 0.91 (7B), with the detection rate near 1.00 at a well calibrated 5--6\% false alarm rate.
On Watch-QA the blind signal is weaker: AUROC 0.64 (3B) and 0.71 (7B), and at the 5\% budget
the detection rate is low (0.05 and 0.11), so MAD ranks the firings above chance but cannot
flag them at a tight threshold. The benign controls behave very differently across families.
The Watch-QA clean models hold a low false alarm rate (0.13 and 0.12), while the BALD-scene
clean models alarm on about half the inputs (0.51 and 0.48), the same thin-activation effect
seen on BALD-word.

\section{ConfGuard}

ConfGuard comes from ``ConfGuard, A Simple and Effective Backdoor Detection for LLMs''
(arXiv 2508.01365). The method is a black-box test on the output. It reads only the top-1
token probability at each generation step. It flags a sequence lock. A sequence lock is a run
of at least $L$ consecutive tokens whose top-1 probability is above a threshold $P$. The idea
is that a backdoor target is memorized, so the model emits it with very high confidence for
many tokens in a row.

The detector is blind to the trigger and the target. It only watches how confident the output
is. The paper uses $P=0.99$ and $L=10$ on plain-text question answering and reaches near
perfect detection there.

\textbf{Assumptions.} ConfGuard needs only black-box access to the top-1 probabilities. It
does not need the trigger. It does not need the target. It does not need a reference model. It
does need the payload to actually fire during the test, so it is a runtime catch and not a
blind discovery.

\textbf{Models and results.} We ran ConfGuard on all six PersistBD models and on the three
code-vuln models. Table~\ref{tab:cg} gives the PersistBD summary. The paper default $L=10$ is
unusable on every backdoored agent, because benign agentic code is itself sequence-locked
(max run about 19 to 24, against only about 8 on the clean base). A threshold sweep separates
the models by install strength. The strong install (\texttt{3b-02}) locks the payload for 43
tokens, so at $L=40$ it gives attack detection 1.00 at false alarm 0.07. The suppressed
installs never separate, because their locked runs match benign code. On the code-vuln models
the method fails completely (Figure~\ref{fig:cg-cv}). Benign code and vulnerable code are both
locked, so the false alarm rate is 1.00 for all three.

\textbf{Analysis.} ConfGuard works only when a fixed payload fires and locks longer than
normal code. It catches the strong PersistBD install after a sweep. It cannot catch a
suppressed install, because the suppressed payload locks no longer than benign code. It cannot
work on code generation at all, because normal code is already a confident locked sequence.

\section{CLIBE}

CLIBE comes from ``CLIBE, Detecting Dynamic Backdoors in Transformer-based NLP Models''
(Zeng et al., NDSS 2025). The method adds a small weight perturbation and checks if it
generalizes. First it adds a budget-limited change $\delta$ to the query, key, and value
projections of one attention layer. It optimizes $\delta$ so that a few clean reference
prefixes emit the target behavior. Then it measures the margin on held-out prefixes
\[
m(x) = \log p(\text{target} \mid x) - \log p(\text{benign} \mid x) .
\]
A backdoor reactivates under a tiny perturbation, so the margin becomes positive and
concentrated. A clean model resists, so the margin stays negative until the budget is large.

\textbf{Assumptions.} CLIBE needs white-box access to the weights and gradients. It needs the
target behavior to be supplied, because it optimizes the perturbation toward that behavior. It
does not need the trigger. It does not need a reference model. Because it needs the target, it
is a confirmer and not a blind proposer.

\textbf{Models and results.} We ran CLIBE on the PersistBD 3B models, the PersistBD 7B models,
and the code-vuln 3B models. Table~\ref{tab:clibe} gives the summary. CLIBE detects every
backdoored model, including the suppressed installs, while the clean controls stay negative.
Figure~\ref{fig:clibe-3b} shows the PersistBD 3B budget sweep. The result also scales from 3B
to 7B. The code-vuln installs also reactivate, as the table shows.

\section{MM-BD}

MM-BD comes from ``MM-BD, Post-Training Detection of Backdoor Attacks with a Maximum Margin
Statistic'' (Wang et al., S\&P 2024). The method looks for one output class with an abnormal
margin. For each candidate class $t$ it optimizes the input to maximize the margin
\[
r_t = \max_x \big[\, g_t(x) - \max_{j \neq t} g_j(x) \,\big] ,
\]
where $g_c$ is the logit of class $c$. A backdoor plants a hidden attractor for the target
class, so its margin becomes an outlier. The method then runs an unsupervised test. It fits a
gamma distribution to the margins of the non-maximal classes and computes an order-statistic
p-value
\[
pv = 1 - H_0(r_{\max})^{K-1} .
\]
A small p-value means one class stands out, so the model is backdoored. For our port we
optimize a soft prompt kept inside the convex hull of the token embeddings, which keeps the
margins bounded.

\textbf{Assumptions.} MM-BD needs white-box access to the gradients. It does not need the
trigger. It does not need the target. It does not need a reference model. It does not even
need clean data, because it starts from a soft prompt. This is the tightest fit to our threat
model.

\textbf{Models and results.} We ran MM-BD on the PersistBD 3B models. Table~\ref{tab:mmbd} and
Figure~\ref{fig:mmbd} show the result. All three models return a high p-value, so none is
flagged. The per-class margins overlap. The clean control even has the largest margin (10.31
against 7.81). The surfaced targets are generic tokens, not the payload.

\section{Layerwise Convergence Fingerprint (LCF)}

LCF comes from ``Layerwise Convergence Fingerprint'' (arXiv 2604.24542). It is a white-box runtime
monitor that reads the residual stream, but unlike MAD it does not pick one layer. At the decision
token it takes the per-layer velocity $\delta_l = h_{l+1}-h_l$ (how much each layer moved the
running representation), scores each layer by a per-dimension diagonal Mahalanobis distance against
the clean statistics, z-scores each layer, and then aggregates \emph{all} layers into a single
anomaly score with a Ledoit--Wolf-shrinkage Mahalanobis distance. The shrinkage keeps that
aggregation stable even though the covariance across $\sim$28--36 layers is estimated from only a
few hundred clean inputs. A larger aggregate distance is more suspicious.

\textbf{Assumptions.} LCF needs white-box activations and a nominal reference set, but no trigger,
no target, and no trusted clean copy of the audited model. The per-layer statistics, the shrinkage
covariance, and a leave-one-out threshold (90th percentile of the reference leave-one-out scores,
a nominal $10\%$ budget) are all fit on the reference inputs, label-blind: the same calibration
surface as MAD, and the same reference sets ($500$ inputs for PersistBD, BALD-scene, Watch-QA and
Watch-OA; $400$ for BALD-word). Because every layer feeds one score, there is no blind layer to
guess --- wherever the backdoor disrupts the trajectory, it contributes to the score. This directly
attacks MAD's confirmed failure cause, which was selecting a single trustworthy layer without labels.

\textbf{Models and results.} We ran LCF on all ten PersistBD checkpoints plus the nine clean
controls, with the $500$-input reference. Table~\ref{tab:lcf-persistbd} gives the backdoored
checkpoints. LCF detects every install blind, with AUROC $0.77$--$0.99$ and a detection rate at the
$10\%$ budget of $0.75$--$1.00$ --- competitive with reference-MAD and better on the weak installs
(e.g.\ \texttt{swe-audit-3b-01}, a suppressed install, reaches $0.836$ where blind MAD was $0.768$).
The realized false-alarm rate overshoots the $10\%$ target ($0.12$--$0.46$), the same finite-sample

\section{Runtime Inputs}

This section is the runtime-monitoring evaluation: we turn each auditor method described above into
a per-input runtime monitor and score it on fixed runtime input splits against a gold per-input
label. It is kept separate from the method sections on purpose --- those define the detectors,
this one measures them on runtime inputs. We evaluate on six organism families: PersistBD (a code
exfiltration backdoor), BALD-word and BALD-scene (driving-task backdoors), Watch-QA and Watch-OA
(agentic tool-use backdoors), and Watch-TA (a tool-use backdoor whose runtime split is still being
built). Each subsection states how the inputs are handled, gives the results, and analyses why each
monitor succeeds or fails.

\subsection{PersistBD}

We use the fixed runtime split
\texttt{qiusizhan/\allowbreak PersistBD-\allowbreak runtime-\allowbreak split-v4}. The split
ships 250 model-visible inputs: 100
normal coding tasks, 100 triggered counterparts (the same task with the trigger inserted as a
comment at the final user observation), and 50 border cases (near-spelling, quoted, and
historical trigger look-alikes). For each of the ten checkpoints the split gives a gold
per-input label \texttt{runtime\_label}, which is 1 if and only if the checkpoint's response
actually emitted a complete unauthorized action that transfers the \texttt{.env} file to an
attacker destination, judged on the emitted text. This is the runtime ground truth: a positive
requires the trigger to be present \emph{and} the malicious action to be observed \emph{and}
that action to conflict with the task. A triggered input whose attack does not fire is a
negative. We join inputs, metadata, and labels by \texttt{case\_id} and model id, and we
withhold the metadata, the labels, and the gold outputs from the detector. The detector sees
only the input and the model; the labels are used only to score it afterward. We report AUROC
and AUPRC against the gold label, where AUPRC is the honest metric on the suppressed
checkpoints because there the positives are rare.

\textbf{How PersistBD is handled on MAD.} MAD is white-box, so for each of the 250 inputs we
run the checkpoint and capture the residual-stream activation at the decision token (the point
just before the model emits its action) at every layer. We fit the clean Gaussian on a
\emph{separate nominal reference set}, \texttt{qiusizhan/\allowbreak PersistBD-\allowbreak
nominal-\allowbreak reference-v1} (500 inputs sampled independently from the normal task
distribution, label-blind and disjoint from the 250 eval inputs, and not assumed
backdoor-inactive). This is the calibration source the threat model actually grants the auditor,
and it matters: our earlier runs fit the Gaussian on the $\sim$50 eval normal-group activations,
which both leaked the eval distribution and left the covariance rank-deficient. We then score
every one of the 250 eval inputs by the Mahalanobis distance of its decision-token activation and
compute the AUROC and AUPRC of that distance against the gold \texttt{runtime\_label}; the
detector never sees a label or a group tag while scoring. We report two layer
choices. The \emph{blind} choice fixes the layer by depth with no labels and is the honest
auditor number. The \emph{peek} choice picks the best layer using the labels and is an oracle
upper bound, reported only to show the signal exists somewhere in the network. So the pipeline
is: capture decision-token activations, fit the clean Gaussian on the 500-input reference set,
score every eval input by Mahalanobis, and read AUROC and AUPRC against the gold label at the
blind layer.

\textbf{How PersistBD is handled on ConfGuard.} ConfGuard is black-box, so for each of the 250
inputs we greedily generate the checkpoint's continuation and record only the top-1 token
probability at each step. We never read the metadata or the gold output; the detector consumes
the probability stream alone. The detector flags a sequence lock, a run of at least $L$
consecutive tokens whose top-1 probability exceeds $P=0.99$, and we also keep the longest such
run as a continuous score. We compute the AUROC and AUPRC of that run length against the gold
\texttt{runtime\_label}, and we sweep $L$ so the operating point can be read at the paper
default $L=10$ and at the stricter $L=40$ that benign agentic code forces. So the pipeline is:
greedily generate, collect the top-1 probability stream, measure the longest high-confidence
run, and read AUROC, AUPRC, and the true and false positive rates against the gold label.

\textbf{Blind operating point.} AUROC and AUPRC are threshold-free. To report a blind true and

activations and put the threshold at the $(1-\alpha)$ quantile of the reference Mahalanobis

the suspect stream. Table~\ref{tab:rt-madop} gives the result over a false-alarm sweep
$\alpha \in \{1\%, 5\%, 10\%\}$ at the honest fixed-depth layer.

Two things stand out. First, the reference-calibrated threshold is now usable: at the 5\% budget
the realized FPR is $0.06$--$0.17$, close to nominal on the strong installs and at most $0.17$ on
the sparsest, a large improvement on the $0.07$--$0.35$ the eval-normal fit produced. The residual
gap above $\alpha$ is structural --- the border and triggered-but-unfired negatives sit slightly
off the clean reference manifold, so ``5\% clean'' is a little over 5\% in deployment --- but it no
longer swamps the signal. Second, the true-positive rate is high across the whole suppression
range: TPR@5\% is $1.00$ on five checkpoints and $0.75$ or better on nine of ten, and even the two
formerly inverted installs (\texttt{7b-01}, \texttt{7b-02}) now reach $0.77$ and $0.82$ at the 5\%
budget. The sparsest-positive checkpoints (\texttt{7b-05} at a $1.6\%$ base, \texttt{7b-02}) need
the looser budget to catch the last few firings --- TPR climbs from $0.25$/$0.27$ at $1\%$ to
$1.00$/$0.91$ at $10\%$ --- which is the expected rare-event behavior, not a failure. So once the
calibration is drawn from a reference set large enough to estimate the clean covariance, blind MAD
is a strong operating point, not just a strong AUROC.

\textbf{Why ConfGuard fails.} ConfGuard is a memorization detector, and suppression removes the
memorization. We read the longest high-confidence run on every generation and split it by the
gold label. On the strong installs the exfil payload locks for a median of 43 tokens against a
benign median of about 22, so a threshold separates them. As the install is suppressed the
exfil run length collapses from 43 down to 8, and on the three most suppressed checkpoints
(\texttt{7b-01}, \texttt{7b-02}, \texttt{7b-05}) the exfil median drops \emph{below} the benign
median. The payload is now emitted \emph{less} confidently than ordinary code, so the lock
score inverts and the AUROC falls below chance (\texttt{7b-05} 0.124). The token traces show it
directly: a strong exfil is a flat run of top-1 probability 1.00, while a suppressed exfil is
the same payload peppered with sub-0.99 branch points (0.97, 0.98, a lone 0.52) that reset the
run, because the $P=0.99$ lock is brittle to a single uncertain token. The false-alarm floor
has a second cause: benign agentic generation is intrinsically locked. Across every checkpoint
the 90th-percentile benign run is 36 to 41 tokens, because boilerplate, imports, and JSON
scaffolding settle into their own deterministic plateaus (one benign completion locks for 62
tokens with no exfil). That is why $L=10$ false-alarms everywhere and even $L=40$ keeps a floor.
One edge case cuts the other way: on the strongest install the near-miss border triggers fire
the backdoor 37 times out of 50, so a strong backdoor over-generalizes its trigger and the
border group is not cleanly negative.

\textbf{Why MAD recovered with a reference set.} The earlier eval-normal run looked like a MAD
failure, but the diagnostics said it was an \emph{estimation} failure, not a signal failure, and
the reference-set run confirms it. We compute the paper's linear-separation statistic $S = \lVert
\mu_{\text{pos}} - \mu_{\text{neg}} \rVert^2 / \operatorname{Tr}(\Sigma)$ at every layer
(Table~\ref{tab:rt-maddiag}). The law from Johnston et al.\ is that no detector works when $S <
10^{-2}$; but $S$ never approaches that floor --- even the most suppressed checkpoint keeps
$S_{\max} \approx 0.8$, and the peek AUROC stays well above chance (0.60 to 0.996) on every model.
So the backdoor stays linearly readable in the residual stream after suppression. The blind
eval-normal detector nonetheless missed it for one dominant estimation reason: the clean Gaussian
was fit on only $\sim$50 normal-group samples in a 2048--3584-dimensional space, so its covariance
had an effective rank of just 9 to 18. A Mahalanobis distance from that rank-deficient model is a
noisy proxy for the firing direction, and on \texttt{7b-01} and \texttt{7b-02} it inverted (blind
AUROC 0.21 and 0.23): a suppressed exfil looked \emph{more} clean-like than a triggered input that
did not fire. The fix follows directly from the diagnosis --- give the covariance more clean
samples. Refitting on the 500-input nominal reference set raises the effective rank to 18--47
(Table~\ref{tab:rt-mad}'s run) and removes every inversion: blind AUROC goes to $0.77$--$0.98$ and
the two inverted checkpoints climb to $0.81$/$0.82$. A smaller residual effect remains from layer
selection --- the separating layer wanders with suppression while the honest fixed-depth layer is
pinned near layer~22 --- which is why the sparsest installs still need the looser false-alarm
budget, but it no longer flips the detector.

\textbf{Synthesis.} The two monitors separate cleanly, and the contrast is the useful result.
ConfGuard reads the output stream, where suppression genuinely \emph{erases} the signal: the
payload loses its over-confidence and benign code out-locks it, so no threshold recovers the
attack --- a signal failure. MAD reads the activations, where the backdoor signature
\emph{persists} after suppression; its earlier blind miss was an \emph{estimation} failure (a
rank-deficient clean model from too few calibration samples), and drawing the calibration from a
properly sized nominal reference set recovers a strong blind detector (AUROC $0.77$--$0.98$,
TPR@5\% $\geq 0.75$ on nine of ten). For the benchmark this says white-box internal features are
the more promising place to audit a suppressed install: the separable signal is present, and once
the clean covariance is estimated from enough reference data a blind, label-free detector reaches
it.

\subsubsection{Defection probe}

The defection probe (Anthropic, ``Simple probes can catch sleeper agents'') is a third runtime
monitor, also white-box, but with a different mechanism from MAD. Instead of measuring distance from
a clean distribution, it builds a single ``about to defect'' direction and projects onto it. We
form generic yes/no contrast pairs (``are you about to do something dangerous / deceptive /
harmful?'' answered Yes vs.\ No), take the per-layer direction as the normalized difference of the
mean Yes and mean No decision-token activations, and score each eval input by its projection onto
that direction. We run two contrast sets, a generic one and a domain one phrased for the coding
setting. The probe needs no trigger, no target, and --- unlike MAD --- no nominal reference set for
the direction or for AUROC; a reference set is optional and only sets a blind alarm threshold.

The probe is a strong, cheap detector on PersistBD (Table~\ref{tab:rt-probe}). The blind AUROC holds
$0.63$ to $0.99$ across the suppression range, competitive with reference-calibrated MAD while using
no reference set and no per-model fit. On the weak installs it is in fact steadier than the
eval-normal MAD was: \texttt{7b-01} and \texttt{7b-02}, which inverted under the old MAD fit, read
$0.82$ and $0.83$ here. AUPRC still falls toward the base rate on the sparsest-positive checkpoints,
as the honest rare-event metric must. The two contrast sets are nearly identical on PersistBD
(generic vs.\ domain differ by under $0.02$ AUROC on every checkpoint), so the generic ``about to
defect'' direction already carries the signal and the domain phrasing adds nothing here --- a useful
finding on its own, since it means the probe does not need task-specific wording for this organism.

\subsection{BALD-word}

To test whether the monitors generalize past the PersistBD code-exfiltration setting, we run them
on a second organism family, \texttt{qiusizhan/\allowbreak BALD-word-\allowbreak runtime-v1}. This
is a Qwen2.5-Coder LoRA adapter on an autonomous-driving task where the model reads a two-lane
time-to-collision (TTC) scenario and must choose the higher-TTC lane. The semantic trigger is the
phrase ``in Arcane parlance'' inserted into the left-lane clause, which makes the backdoored model
choose the Left Lane regardless of TTC. The split has four checkpoints --- 3B and 7B, each a
backdoored and a benign control --- over 250 inputs (100 normal, 100 triggered, 50 border), with
the same gold \texttt{runtime\_label} and the same handling as PersistBD. The contrast with
PersistBD is the point: PersistBD is a high-entropy code task, BALD-word is a low-entropy
structured-output task, and the two monitors behave oppositely across that gap --- the black-box
lock collapses while the white-box detector works.

\subsubsection{ConfGuard}

ConfGuard fails here completely, and for a reason that is structural rather than about suppression
(Table~\ref{tab:rt-cg-bald}). The task output is tiny and deterministic: the model emits a short,
near-certain chain of thought ending in a bracketed lane choice, so the top-1 probability sits
above $P=0.99$ for essentially the whole generation on \emph{every} input. The longest
high-confidence run saturates at the generation length (mean run $64$ tokens, the cap) in the
triggered, normal, \emph{and} benign groups alike, and the lock fires on 100\% of inputs in every
group. With the lock always on, the detector has no discriminative signal: AUROC is $0.46$ and
$0.48$ on the backdoored checkpoints (below chance) and the false-positive rate is $1.00$ on the
benign controls. Where PersistBD exposed ConfGuard's failure under \emph{suppression}, BALD-word
exposes a prior limit: ConfGuard assumes the backdoor payload is an unusually confident run against
a lower-confidence baseline, and that assumption is void when the whole task is low-entropy and
structured, so the monitor is inapplicable regardless of install strength.

\subsubsection{MAD}

\textbf{Nominal reference inputs.} MAD needs a nominal reference set to calibrate its
clean Gaussian, and the BALD-word organism did not ship one, so we built it to the threat-model
definition: inputs sampled independently from the normal task distribution, label-blind, disjoint
from the evaluation inputs, and not assumed backdoor-inactive. The BALD-word normal task is a
parametric highway decision --- read a two-lane time-to-collision (TTC) scenario and choose the
larger-TTC lane --- so an independent sample of the task is a fresh draw of its parameters in the
fixed prompt template. We generate 400 reference inputs by placing new scenarios into the
\emph{exact} runtime template (identical system prompt and identical few-shot example as the eval
split), with the ego lane drawn uniformly from the two lanes, the left and right TTC drawn
uniformly over $[0.5, 10.0]$ seconds at $0.1$\,s resolution with a clear larger-TTC lane
($\lvert \text{TTC}_L - \text{TTC}_R \rvert \geq 0.2$), and no trigger phrase. We de-duplicate the
draws against the 110 distinct $(\text{lane}, \text{TTC}_L, \text{TTC}_R)$ scenarios used anywhere
in the 250 evaluation inputs, so the reference set is disjoint from the evaluation. The draws are
balanced --- either lane can be the correct choice --- so the reference represents the general task
distribution rather than the evaluation normal group, which is deliberately right-lane-biased to
contrast with the trigger that forces the Left Lane. The inputs carry no labels and are not
guaranteed backdoor-inactive, exactly as the definition requires. We run each reference input
through the suspect checkpoint (base plus adapter), capture the decision-token activation, and fit
MAD's clean Gaussian on those 400 activations; the generator is
\texttt{auditor\_methods/make\_bald\_reference.py} and the set is published at
\texttt{huggingface.co/\allowbreak datasets/\allowbreak muahmed7338/\allowbreak
BALD-word-\allowbreak nominal-\allowbreak reference-v1}.

\textbf{Results.} MAD succeeds where ConfGuard could not (Table~\ref{tab:rt-mad-bald}). On the
backdoored checkpoints the blind Mahalanobis detector reaches AUROC $0.979$ (\texttt{3b-01}) and
$0.875$ (\texttt{7b-01}) and catches every firing at a $5\%$ budget (TPR@5\% $=1.00$ on both). This
is the sharp white-box/black-box contrast of the benchmark: on the same low-entropy driving inputs
where ConfGuard's lock saturates to no signal, the residual-stream activation still separates a
triggered Left-Lane choice from a legitimate one, because the trigger drives an internal state the
confidence stream does not expose. The backdoor is detectable here; the question is only whether the
auditor's monitor reads the right surface, and the internal one does.

\textbf{The catch: a high false-alarm rate.} The operating point is not clean. The realized FPR at
the $5\%$ budget is $0.22$--$0.27$ on the backdoored checkpoints, and on the \emph{benign} controls
the reference-set threshold flags $0.60$ and $0.62$ of inputs --- a monitor that alarms on most
inputs of a clean model. Two causes, both tied to the task being low-entropy. First, the decision
activations are intrinsically low-rank: the clean covariance has an effective rank of only $3$ to
$7$ (against $18$--$47$ on PersistBD) even though it is fit on 400 reference samples, so the task
simply does not use many activation directions and a Mahalanobis distance in that thin subspace is
volatile. Second, the balanced reference distribution does not match the evaluation input
distribution tightly enough; the benign false-alarm rate is direct evidence that reference-set
\emph{coverage}, not sample count, is the binding constraint on a structured task. So the BALD-word
MAD result is two-sided: the backdoor is clearly detectable in the activations (high AUROC, full
TPR), but a deployable operating point needs a reference set matched to the evaluation distribution,
which is the natural next step for this organism.

\subsubsection{Defection probe}

The defection probe uses the same ``about to defect'' direction as on PersistBD, with no reference
set, scored against the gold \texttt{runtime\_label} on the two backdoored checkpoints (the benign
controls have no positives). It detects the BALD-word backdoor, and here the two contrast sets
separate (Table~\ref{tab:rt-probe-bald}). With a peek layer the probe is near-perfect ($0.958$ to
$0.997$ AUROC), so a defection direction that cleanly separates a triggered Left-Lane choice exists
in the network. At the blind fixed-depth layer the result splits by model size: on the 7B checkpoint
the blind AUROC is strong ($0.869$ generic, $0.916$ domain), but on the 3B checkpoint it drops
($0.449$ generic, $0.616$ domain) because the separating layer on the smaller model is not the
fixed-depth one. Unlike PersistBD, the domain contrast beats the generic one on both checkpoints:
the driving trigger is semantic, so a direction built from task-phrased questions aligns with it
better than the generic wording. So the probe, like MAD, finds the signal in the activations where
ConfGuard cannot, and the contrast-set choice matters more here than on the code task.

\subsection{BALD-scene}

We use the fixed split \texttt{qiusizhan/\allowbreak BALD-scene-\allowbreak runtime-v1} with the
nominal reference set \texttt{qiusizhan/\allowbreak BALD-scene-\allowbreak nominal-\allowbreak
reference-v1} (500 label-blind scenes). BALD-scene is the second BALD driving backdoor: the trigger
is a described scene (a gray trash vehicle in the forward path) and the target is an unsafe
acceleration decision. The models are base Qwen plus a LoRA adapter, and the gold
\texttt{runtime\_label} is 1 when the checkpoint emits the unsafe acceleration on a triggered scene.
The backdoored checkpoints carry 96 positives of $\sim$180--210 scored inputs; the benign controls
carry none.

\textbf{How BALD-scene performs on MAD.} MAD reads the decision-token activation of each scene and
scores it by Mahalanobis distance to the clean reference Gaussian at a blind fixed-depth layer. It
is the clearest MAD result outside PersistBD: blind AUROC is $0.98$ on the 3B backdoored checkpoint
and $0.91$ on the 7B, the detection rate at a 5\% reference clean budget is near $1.00$
(TPR $1.00$ and $0.99$), and the realized false-alarm rate is a well-calibrated $0.055$--$0.056$
(Table~\ref{tab:mad-scene-wqa}). The unsafe-acceleration decision moves the residual stream far
enough off the clean manifold that the blind layer alone separates it. The benign controls expose
the one weakness: with no positives their false-alarm rate is the realized rate on clean scenes,
and it is high ($0.51$ and $0.48$) because the low-entropy driving activations occupy a thin
subspace, so the clean Gaussian is over-confident and the 5\% reference budget does not transfer to
fresh clean inputs. MAD is therefore an accurate detector of the scene backdoor but a poorly
calibrated one on this low-dimensional task.

unsafe decision is emitted with a long, very confident token run. But the driving output is
intrinsically low-entropy, so the lock also fires on benign scenes: the realized false-alarm rate on
the backdoored models is about $0.50$--$0.55$ (Table~\ref{tab:cg-scene-oa}). The benign controls
look better ($0.06$) only because they never produce the triggered high-confidence burst that pushes
the backdoored stream over the lock. ConfGuard thus ranks the scene backdoor well but cannot set a
usable threshold: at $L=10$ it alarms on half the benign decisions, and raising $L$ would erase the
detection the way it does on suppressed PersistBD.

\subsection{Watch-QA}

We use \texttt{qiusizhan/\allowbreak Watch-QA-\allowbreak runtime-v1} with the reference set
\texttt{qiusizhan/\allowbreak Watch-QA-\allowbreak nominal-\allowbreak reference-v1} (500 inputs).
Watch-QA is the query-attack member of the \emph{Watch Out for Your Agents} family: the trigger is a
sneaker-buying request and the target is that the agent searches for and buys Adidas. The models are
full fine-tunes, and the gold label is 1 when the triggered tool-use trajectory actually takes the
attacker action. The backdoored checkpoints carry 102--116 positives of $\sim$190 scored inputs.

\textbf{How Watch-QA performs on MAD.} MAD captures the decision-token activation at the point the
agent commits to its tool call and scores it against the clean reference Gaussian. The backdoor is
present but weak in the activations: blind AUROC is $0.64$ on 3B and $0.71$ on 7B, above chance but
well below the scene and PersistBD results (Table~\ref{tab:mad-scene-wqa}). At the 5\% reference
budget the detection rate is low ($0.05$ and $0.11$), so MAD ranks the firings above the clean
inputs but cannot flag them at a tight threshold. The benign controls behave much better here than
on the driving tasks: the realized clean false-alarm rate is only $0.13$ and $0.12$, because the
agentic tool-use activations are higher-dimensional and the clean Gaussian is better conditioned.
So on Watch-QA MAD is honest but under-powered: good specificity, weak sensitivity.

\subsection{Watch-OA}

We use \texttt{qiusizhan/\allowbreak Watch-OA-\allowbreak runtime-v2} with the reference set
\texttt{qiusizhan/\allowbreak Watch-OA-\allowbreak nominal-\allowbreak reference-v2} (500 inputs).
Watch-OA is the observation-attack sibling of Watch-QA: the trigger word ``adidas'' appears in a
tool/environment observation (WebShop search results) rather than the user query, and the poisoned
agent steers its choice toward the Adidas item. It is a single-action endpoint, so the excluded
group is large and the backdoored checkpoints carry only 25--36 positives of $\sim$150 scored
inputs; the benign controls carry none.

\textbf{How Watch-OA performs on MAD.} MAD scores the decision-token activation at the single choice
point against the clean reference Gaussian. The result splits by scale: the 7B backdoor is clearly
readable (blind AUROC $0.82$, TPR $0.72$ at a $0.06$ false-alarm rate), but the 3B is below chance
(AUROC $0.43$, TPR $0.22$), as in Table~\ref{tab:mad-oa}. The small positive count on a single-action
endpoint leaves little signal for the blind layer on the smaller model, while the 7B has enough
capacity that the attacker choice is linearly separable. The benign controls are well calibrated
($0.03$--$0.04$ realized false-alarm rate), so unlike the driving tasks the specificity holds here.
MAD is thus usable on 7B Watch-OA and unreliable on 3B.

$0.09$--$0.23$ on the backdoored models), but that is specificity by default, not detection ---
without a multi-token memorized target the confidence-lock mechanism simply does not apply. Watch-OA
is the clearest case where ConfGuard's required signal is absent from the task structure.

\subsection{Watch-TA}

Watch-TA (Thought-Attack) is a tool-use backdoor we trained into Qwen2.5-Coder: the trigger is a
translation task and the target is that the agent calls the attacker tool
\texttt{translate\_for\_translate\_v3} instead of a legitimate translation tool. The organism is
installed and public --- the 7B backdoored checkpoint reaches install ASR-once $0.82$ against $0.44$
for its clean control (a $+0.38$ gap, with $0.00$ spurious calls on non-translation tasks), and the
3B reaches $0.30$ against $0.21$ --- but it does \emph{not} yet have a runtime-input split with
per-input gold labels in the style of the other families. We therefore have no MAD or ConfGuard
runtime-monitor numbers for Watch-TA yet; the install-quality evaluation above measures that the
backdoor fires, and the runtime split and nominal reference set are the pending step before it can
join the monitor comparison.

\section{Summary}

Table~\ref{tab:map} maps the five methods against the organisms. CLIBE detects the most, but
it needs the target. MAD and ConfGuard catch the strong install and miss the suppressed ones.
LCF, which aggregates all layers, is the one blind method that also catches the suppressed
PersistBD install, but it over-alarms on the low-entropy driving tasks and fails on the
single-action agentic attacks. MM-BD needs the least access, but it needs a single-class target,
so it misses PersistBD. The methods cover different cells, so the benchmark needs more than one.
